If a colour fails 4.5:1 against white button text, the system suggests the nearest darker shade that passes.

13 · Accessibility & content

WCAG 2.2 AA, everywhere

Accessibility requirements override brand choices when they conflict. Test with axe in CI and with NVDA, JAWS, VoiceOver and TalkBack every sprint that touches UI.

Keyboard

Everything reachable, visible 2px purple focus ring, no traps, skip links.

Live regions

Polite for updates, assertive for errors. Never steal focus.

Low vision

200% text resize, reflow at 400% (320px), high-contrast & forced-colours.

Floor audio

Spoken prompts, distinct sound + vibration for each scan result.

Do
  • Sentence case, verbs on buttons: Release wave
  • Errors with a next step: Scan bin A04-12-C-02
  • Use --*-text tokens for status text
  • Pair every status colour with an icon and a label
  • Pull every string from the translation catalog
Don't
  • Title Case Or ALL CAPS buttons: SUBMIT
  • Vague errors: Something went wrong
  • Use success-700 or warning-600 for small text
  • Rely on red/green alone to show state
  • Add decorative motion on floor screens
